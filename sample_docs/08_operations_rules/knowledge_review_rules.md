# Knowledge Review Rules

Source ID: ops-knowledge-review

## Review Cadence

High-traffic articles are reviewed monthly. API-related articles are reviewed after each API release. Incident-related articles are reviewed after every SEV1 or SEV2 postmortem.

## Review Triggers

- Three or more not helpful votes in seven days.
- Article appears in top ten searches but has low click-through.
- Product behavior changed in release notes.
- Related error code was renamed or retired.

## Ownership

The knowledge owner drafts changes. Engineering reviews API examples and incident root cause language. Support operations approves customer-facing publication.

## Retirement

Retire articles when the workflow no longer exists, the error code is obsolete, or the article duplicates a newer canonical source.
