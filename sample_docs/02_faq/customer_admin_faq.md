# Customer Admin FAQ

Source ID: faq-customer-admin

## How do I add a new support agent?

Open Admin Settings, choose Users, select Invite user, enter the work email, and assign a role. Invited users appear as pending until they accept.

## Why can an invited user not see a queue?

Queue access is controlled by team membership. Add the user to the queue owner team or give them Support Admin access.

## Can I rename a queue after launch?

Yes. Existing conversations keep their queue history, while new reports display the updated queue name. Avoid renaming queues during active incidents because it can confuse handoff notes.

## How are API keys managed?

Support Admins can create, rotate, and revoke API keys from Admin Settings > Developer Access. Keys should be rotated after team ownership changes or suspected exposure.

## Can customers see internal notes?

No. Internal notes are agent-only and are excluded from customer email, web widget history, and public export links.
